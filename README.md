              桐陰祭 136-2 信号システム 取扱説明書 
======================================================================

このシステムは、桐陰祭における進行管理および安全確認をリアルタイムで
行うためのWebシグナルシステムです。
 https://hayatokiha40-arch.github.io/ToinFes2-2/ 
 

----------------------------------------------------------------------
【1. 各端末の役割（全8種＋管理者）】
----------------------------------------------------------------------

【受付】
  ・進行のスタート地点前の受付担当端末。
  ・「案内」ボタンを押してスタート地点へ来客を通知します。
  ・スタートおよび場所1〜4の「準備状況」をリアルタイムで監視します。

【スタート】
  ・スタート地点の担当端末。
  ・「スタート」ボタンを押して全体の進行を開始させます。
  ・受付からの「来客」通知を受け取るほか、場所1〜4の準備状況を監視します。

【場所1 〜 場所4】
  ・各エリアの担当端末。
  ・自身の場所のステータス（準備中 / 準備完了 / 非常）を切り替えます。
  ・スタートからの「スタート通知」を受け取ります。

【出発信号】
  ・コース/アトラクション入口等に設置するシグナル画面端末。
  ・場所1〜4の準備状況に応じて自動的に画面表示が切り替わります。

【接近】
  ・進行ルート途中に設置するシグナル画面端末。
  ・スタートの進行状況に応じて自動的に画面表示が切り替わります。

【管理者】
  ・全体の接続状況・ステータス・信号状態を一覧で確認できるモニタ画面です。
  ・閲覧にはパスワードが必要です。


----------------------------------------------------------------------
【2. 基本的な起動・設定手順】
----------------------------------------------------------------------

1. ブラウザでシステムを開きます（このページトップのURLより）。
2. 「端末の役割を設定してください」という画面が表示されます。
3. ドロップダウンメニューから、自分が担当する役割を選択します。
4. 「この役割で開始する」ボタンを押します。

※「管理者」を選択した場合はパスワード入力が求められます。
※すでに他の端末で同じ役割が使われている場合、警告ダイアログが表示されます。
※画面右上の「役割を変更」ボタンを押すと、いつでも役割を変更・選び直せます。


----------------------------------------------------------------------
【3. 役割ごとの具体的な操作方法】
----------------------------------------------------------------------

■ 受付端末の操作
  1. 画面上部の緑色の「案内」ボタンを押すと、スタート端末へ「来客」の横帯通知が飛びます。
  2. 画面下部のグリッドで、スタート・場所1〜4が「準備完了」になっているか確認できます。
  ※スタート地点が「準備中」または「非常」のときに「案内」を押すと確認ダイアログが出ます。

■ スタート端末の操作
  1. 受付から「案内」が押されると、画面上部に青い帯で「来客」と10秒間表示されます。
  2. 場所1〜4の状況を確認し、準備が整ったら画面上部の「スタート」ボタンを押します。
  3. 「スタート」を押すと、場所1〜4へ「スタート」通知（20秒間）が飛び、自分のステータスは自動的に「準備中」に戻ります。
  ※非常や準備中の場所がある状態で「スタート」を押すと確認ダイアログが出ます。

■ 場所1 〜 場所4 端末の操作
  1. 画面に「準備中」「準備完了」「非常」の3つの大きなボタンが表示されます。
  2. 自分のエリアの状況に合わせてボタンをタップして状態を切り替えてください。
     ・【準備中】（白）：次の受け入れ準備をしている状態
     ・【準備完了】（青）：いつでもスタートしてOKな状態
     ・【非常】（赤）：（自分では解決できない）問題発生・一時停止したい状態
  3. スタート端末から「スタート」が押されると、画面上部に「スタート」と20秒間表示され、自動的に「準備中」に戻ります。

■ 出発信号 / 接近 端末の操作
  ・ボタン操作はありません。画面の明るさを調整し設置して画面を表示したままにしてください。
  ・動作仕様は「4. 信号・点滅の動作ルール」を参照してください。

■ 管理者 画面
  ・すべての役割の接続状態、現在のステータス、各信号の点灯状態が表形式でリアルタイム表示されます。


----------------------------------------------------------------------
【4. 信号・点滅の動作ルール（重要）】
----------------------------------------------------------------------

【出発信号の動き】
  ・接続されているすべての「場所1〜4」が【準備完了】になると ──＞ 画面全体が「白点灯」
  ・接続されている場所1〜4のどこか1つでも【非常】になると ──＞ 画面全体が「赤点滅」
  ・それ以外（準備中がある等） ──＞ 画面は「黒（消灯）」

【接近の動き】
  ・スタート端末で「スタート」ボタンが押されると ──＞ 画面全体が「白点灯」
  ・接続されている場所1〜4のどこか1つでも【非常】になると ──＞ 画面全体が「赤点滅（最優先）」
  ・受付で「案内」が押されるか、初期状態 ──＞ 画面は「黒（消灯）」

【非常点滅ルール】
  ・場所1〜4のいずれかで「非常」が押された場合、受付・スタート画面の該当枠だけでなく、
    「出発信号」「接近」の画面全体も赤く点滅します。
  ・安全確認が取れたら、該当の場所端末で「準備中」または「準備完了」に切り替えると解除されます。


----------------------------------------------------------------------
【5. トラブルシューティング・注意事項】
----------------------------------------------------------------------

Q. 「別の端末がこの役割を選択したため、切断されました」と出た
A. 他の人が同じ役割（例: 場所1）を後から選択した可能性があります。
   担当者同士で話し合い、正しい役割を選び直してください。

Q. 通信が途切れた／「未接続」と表示される
A. Wi-Fiやモバイル回線の接続を確認し、画面をリロード（再読み込み）して役割を選び直してください。
   ※端末が通信不能になると、5秒後に他端末から「未接続」として扱われます。

Q. 信号画面や通知帯が出ない
A. 「出発信号」や「接近」端末には、誤動作防止のため「来客」「スタート」の通知帯は出ない仕様になっています。
