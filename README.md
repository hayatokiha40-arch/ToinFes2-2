# 桐陰祭 136-2 信号システム

桐陰祭における進行管理および安全確認をリアルタイムで行うためのWebシグナルシステムです。

* **システムURL**: https://hayatokiha40-arch.github.io/ToinFes2-2/

---

## 端末の役割一覧

| 役割 | 画面種別 | 主な機能・役割 |
| :--- | :--- | :--- |
| **受付** | 監視・操作 | 「案内」送信、全体状況の監視 |
| **スタート** | 監視・操作 | 「スタート」送信、「来客」通知受信、各場所の監視 |
| **場所 1〜4** | クライアント | 自身のステータス変更（準備中 / 準備完了 / 非常） |
| **出発信号** | シグナル表示 | 場所1〜4の準備完了・非常状態に応じた画面表示 |
| **接近** | シグナル表示 | スタート状況・非常状態に応じた画面表示 |
| **管理者** | 全体監視 | 全端末の接続・ステータス一覧表示（要パスワード） |

---

## 基本的な起動・設定手順

1. ブラウザでシステムを開きます（ページ上部のURLより）。
2. **「端末の役割を設定してください」** 画面で、自身の担当する役割を選択します。
3. **「この役割で開始する」** ボタンを押して開始します。

> [!NOTE]
> * 「管理者」の選択にはパスワードが必要です。
> * 他の端末が使用中の役割を選ぶと警告が表示されます。
> * 画面右上の **「役割を変更」** ボタンからいつでも役割を選び直せます。

---

## 役割ごとの具体的な操作方法

### 1. 受付端末の操作
* **「案内」ボタン**: 画面上部の緑色のボタンを押すと、スタート端末へ「来客」の横帯通知が飛びます。
* **画面監視**: 画面下部のグリッドで、スタート・場所1〜4が「準備完了」になっているか確認できます。
  * ※スタート地点が「準備中」または「非常」のときに「案内」を押すと確認ダイアログが出ます。

### 2. スタート端末の操作
* **「来客」通知**: 受付から「案内」が押されると、画面上部に青い帯で「来客」と10秒間表示されます。
* **「スタート」ボタン**: 場所1〜4の状況を確認し、準備が整ったら画面上部のボタンを押します。
  * 場所1〜4へ「スタート」通知（20秒間）が飛び、自身のステータスは自動的に「準備中」に戻ります。
  * ※非常や準備中の場所がある状態で「スタート」を押すと確認ダイアログが出ます。

### 3. 場所 1 〜 場所 4 端末の操作
画面上の大きな3つのボタンで自身の状態を選択・切替します。
* **【準備中】（白）**: 次の受け入れ準備をしている状態
* **【準備完了】（青）**: いつでもスタートしてOKな状態
* **【非常】（赤）**: （自分では解決できない）問題発生・一時停止したい状態

※スタート端末から「スタート」が押されると、画面上部に「スタート」と20秒間表示され、自動的に「準備中」に戻ります。

### 4. 出発信号 / 接近 端末の操作
* ボタン操作はありません。画面の明るさを調整し設置して画面を表示したままにしてください。
* 動作仕様は下記の「信号・点滅の動作ルール」を参照してください。

### 5. 管理者画面
* すべての役割の接続状態、現在のステータス、各信号の点灯状態が表形式でリアルタイム表示されます。

## 信号・点滅の動作ルール（重要）

### 1. 出発信号の動き
| 条件 | 画面表示 |
| :--- | :--- |
| 接続されている場所1〜4の**どこか1つでも【非常】** | **赤点滅（最優先）** |
| 接続されているすべての「場所1〜4」が**【準備完了】** | **白点灯** |
| それ以外（準備中がある等） | **黒（消灯）** |

### 2. 接近の動き
| 条件 | 画面表示 |
| :--- | :--- |
| 接続されている場所1〜4の**どこか1つでも【非常】** | **赤点滅（最優先）** |
| スタート端末で**「スタート」ボタンが押された** | **白点灯** |
| 受付で「案内」が押された／初期状態 | **黒（消灯）** |

> [!IMPORTANT]
> **非常点滅ルール**  
> 場所1〜4のいずれかで「非常」が押された場合、受付・スタート画面の該当枠だけでなく、「出発信号」「接近」の画面全体も赤く点滅します。  
> 安全確認が取れたら、該当の場所端末で「準備中」または「準備完了」に切り替えると解除されます。

## トラブルシューティング・注意事項

<details>
<summary><b>Q. 「別の端末がこの役割を選択したため、切断されました」と出た</b></summary>
他の人が同じ役割（例: 場所1）を後から選択した可能性があります。担当者同士で話し合い、正しい役割を選び直してください。
</details>

<details>
<summary><b>Q. 通信が途切れた／「未接続」と表示される</b></summary>
Wi-Fiやモバイル回線の接続を確認し、画面をリロード（再読み込み）して役割を選び直してください。  
※端末が通信不能になると、5秒後に他端末から「未接続」として扱われます。
</details>

<details>
<summary><b>Q. 信号画面や通知帯が出ない</b></summary>
「出発信号」や「接近」端末には、誤動作防止のため「来客」「スタート」の通知帯は出ない仕様になっています。
</details>
